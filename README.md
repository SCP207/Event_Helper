# Event_Helper_SL_EXILED
This plugin provides 13 useful commands (this count doesn't include the reset command) for running events

Use `ehhelp` to see the list of commands

**Format:** Command - Command description - Permission

1. infammo - Toggles if there is infinite ammo in an inventory - eh.infammo

2. infammoingun - Toggles if ther is infinite ammo in guns - eh.infammo

3. wavesenabled - Toggle if waves are enabled or not - ev.wavesenabled

4. giveall - Gives all players an item rather than just 1 - Base giving items permission

5. giveitemonwave - Spawn waves giving items - eh.wavegiveitems

6. giveeffectonspawn - Spawn waves giving effects - eh.wavegiveeffects

7. stopteslas - Toggles if teslas fire - eh.stopteslas

8. spawningwithitem - Prevent people from spawning with items - eh.noitemspawn

9. doorsbreaking - Toggles if doors are indestructible - eh.indestructible

10. windowsbreaking - Toggles if windows are indestructible - eh.indestructible

11. lockingdoors - Allows people to lock any door (like bypass) - eh.lockingdoors

12. amountofdroppeditems - Allows you to locate the amount of a dropped items - eh.locateitems

13. disablepickups - Allows you to prevent people from picking up specific items - eh.pickups

14. ehreset - Allows you to reset all commands in the plugin to their default states - eh.resetcommands

15. transferitem - Transfers a players held item (or an item is a slot of your choice) to another player - eh.transfer
